## MediaFlow v581 Stable

### Reorder a title's parts
Edit title → **By parts**: each part has a **drag handle** (⠿), **↑ / ↓** arrows and a **position number** — drag a part, nudge it, or type where it goes. The order is saved with the title, and every place that logs it follows it: the part chips and cards in Logging (Quick and Advanced), Log any title and Batch Log. Each part keeps its own counter, unit and time per unit when it moves.

Matches MediaFlow app 11.1.0.581.
